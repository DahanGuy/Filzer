# Filzer

A fully-featured iOS/iPadOS 15+ file manager inspired by [Filza](https://www.tigisoftware.com/default/?page_id=78), built with SwiftUI and [PartyUI](https://github.com/jailbreakdotparty/PartyUI).

## Why make this

"Filza is already a great iOS/iPadOS file manager, why make an alternative?" well Filza is kinda old and outdated, its UI is not appealing and it is NOT open source, meaning adding sandbox escape exploits to it requires making a tweak (e.g. [FilzaJailedDS](https://github.com/34306/FilzaJailedDS)) instead of making a PR or a fork.

## Features

- **Archive Support** - Create ZIP, TAR, TAR.GZ and TAR.BZ2 and extract RAR, 7Z, GZIP, BZIP2 and XZ
- **Text Editor** - Plain-text editing with find/replace
- **Hex Editor** - Byte-level viewer/editor with find, go-to-offset and inline byte editing
- **Plist Editor** - Full Plist editor with type changing, key renaming and more
- **Image Viewer** - Image displaying and metadata
- **Media Player** - Audio/video playback and metadata
- **SQLite Viewer** - Browse tables and run SQL queries
- **IPA Inspector** - App icon, bundle ID, version, minimum iOS and extract or browse contents
- **Provisioning Profile Viewer** - Profile details, validity, devices and entitlements
- **Web Viewer** - uses WebKit to display HTML files
- **Network Locations** - WebDAV, FTP/FTPS and SMB file shares, and Dropbox, Google Drive and OneDrive as Cloud Network Locations
- **Biometric Lock** - Face ID / Touch ID or Passcode app lock
- **Permissions Editor** - set read/write or execute permissions for owner, group and others.
- **Root Access** (TrollStore and .deb builds) - file operations run as root through a bundled helper, falling back to regular (mobile) access if root isn't available

## Requirements

- Xcode 13+ (with iOS/iPadOS SDK)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)

## TrollStore and .deb builds

These builds bundle `FilzerRootHelper`, a small command-line tool that Filzer spawns as root (using the `com.apple.private.persona-mgmt` entitlement) to read and edit protected folders. If the helper is missing or can't start as root, Filzer uses regular (mobile) access instead. It can be turned off in Settings > General > Run as Root.

To package it, build the helper with `scripts/build-root-helper.sh <output> iphoneos`, then sign both it and the app with `Resources/Filzer.entitlements` using ldid and place it next to the app executable. The CI workflow does this for the `.tipa`.

On a Mac, `scripts/build-root-helper.sh build/helper` followed by `scripts/test-root-helper.sh build/helper` tests the helper's file operations.
